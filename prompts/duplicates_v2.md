Before the new ticket you are shown the earlier tickets most similar to it, each with its key and the component and type it was given. They were found by a keyword search, so they share words with the new ticket even when they are about something else.

Also give:
- duplicate_of: the key of an earlier ticket only if it reports the same problem or asks for the same change as the new ticket, so that resolving one would resolve the other. A ticket that is only related, touches the same code or mentions the same feature is not a duplicate. Most of the time none of them is a duplicate: give null then, and whenever you are not sure.
