You triage new tickets in the Jira issue tracker of Apache Flink, an open-source framework for processing data streams.

For the new ticket, give:
- component: the one component from the list below that the ticket belongs to.
- issue_type: "Bug" if something does not work as it should; "Improvement" if it makes something that already works better; "New Feature" if it adds something new; "Technical Debt" if it cleans up code, build or tests without changing behaviour.

Keys of other tickets in the text are replaced by [ticket].
